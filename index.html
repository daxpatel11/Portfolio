Gradial · Agentic AI

QA built into AI campaign agents

Gradial's agents assemble email and push campaigns. I built MCP submission and status tools so agents can request QA, follow the same job and return its report.

Engineering decisions & ownership
Problem
Campaign-authoring agents need validated inputs and dependable access to long-running QA results.
My contribution
MCP tools, channel-specific skill instructions, job-status tracking and report integration for Walmart and Sam's Club workflows.
Design choice
Separate submission from status polling. Skill instructions tell the agent not to resubmit accepted jobs; this is not a claim of transport-level exactly-once delivery.
Evidence
Implemented submit/status workflows and regression coverage. Internal source and campaign data are not published here.

Enterprise Martech QA Agent

AI quality gate for email and push

Rules, LLM and vision checks across copy, brand safety, links, landing pages, tracking, accessibility and rendering, turned into plain-language fixes.

How I make AI findings trustworthy
Approach
Use deterministic validation for structured rules and model-assisted analysis for contextual checks.
Failure handling
Distinguish unavailable checks from passed checks; preserve evidence and test known failure cases rather than treating job completion as QA success.
My contribution
Backend validation, MCP integration, report presentation and regression tests across email and push workflows.

Email + Push QA

Personalised, multi-device confidence

Hydrated email checks with inbox rendering and dark mode, plus Android and iOS push checks for deep links, attribution and imagery.
